# Site AlerteGR20

Interface Next.js du produit décrit dans le [README à la racine](../README.md).

```bash
npm install
npm run dev
```

Le site de développement est sur http://localhost:3000. Il appelle l'API indiquée par `NEXT_PUBLIC_API_URL`.

Les pages publiques, le sitemap et la vérification Google Search Console sont décrits dans le README à la racine.
